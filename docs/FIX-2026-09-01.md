### 2.4 [NEW-01 / E-04] 스크롤 이벤트 리스너의 DOM 미참조 TypeError 제거
* **무엇이 틀렸나**:
  - `index.html` 스크립트 실행 시점(2450줄 부근)에 `const scrollTopBtn = document.getElementById('scroll-top-btn');`를 전역에서 즉시 실행했습니다.
  - 그러나 `<button id="scroll-top-btn">` 요소는 `<script>` 닫힘 태그 아래(2657줄)에 선언되어 있어, 스크립트 로드 시점에는 DOM 트리에 아직 존재하지 않아 `scrollTopBtn`이 항상 `null`로 초기화되었습니다.
* **어떤 증상이 났나**:
  - 브라우저 검증 시 페이지 스크롤이나 `showScreen()` 화면 전환(`window.scrollTo`)이 발생할 때마다 콘솔에 **`Uncaught TypeError: Cannot read properties of null (reading 'classList')`** 에러가 반복적으로 발생(검증 1회당 29회 발생)했습니다.
* **수정 전 코드 (`index.html:2449-2457`)**:
  ```javascript
    // ====== SCROLL TO TOP ======
    const scrollTopBtn = document.getElementById('scroll-top-btn');
    window.addEventListener('scroll', () => {
      if (window.scrollY > 600) {
        scrollTopBtn.classList.add('visible');
      } else {
        scrollTopBtn.classList.remove('visible');
      }
    }, { passive: true });
  ```
* **수정 후 코드 (`index.html:2449-2458`)**:
  ```javascript
    // ====== SCROLL TO TOP ======
    window.addEventListener('scroll', () => {
      const btn = document.getElementById('scroll-top-btn');
      if (!btn) return;
      if (window.scrollY > 600) {
        btn.classList.add('visible');
      } else {
        btn.classList.remove('visible');
      }
    }, { passive: true });
  ```
* **수정 이유**:
  - 스크롤 이벤트 발생 시점에 요소를 지연 조회(Lazy Lookup)하고 널 체크(`if (!btn) return;`)를 수행함으로써 런타임 에러를 완전히 근절했습니다.

## 3. 판단 보류 (사용자 결정 필요 항목)

대원칙(전체 틀 유지, 임의의 카피/구조 변경 금지)에 따라 코드 수정을 진행하지 않고 보류한 항목들입니다.

1. **인트로 및 메타태그의 "10개 질문" 문구 (`index.html:13, 1653, 1660`)**:
   - **현상**: 메타태그(`og:description`) 및 랜딩 카피에 `"10개 질문으로 진단"`, `"10개 질문 · 1분"`으로 표기되어 있으나, v7 체계에서는 카테고리별로 각 6개 문항이 출제됩니다 (카테고리 화면 1715줄에는 "6~7개 질문이면 끝나요"로 적힘).
   - **보류 사유**: 마케팅 카피 톤 변경에 해당하므로 개발자가 임의 수정하지 않고 기획/운영 판단에 위임합니다.
2. **Hero 스탯 숫자의 "10분" 표기 (`index.html:1451`)**:
   - **현상**: `<span class="hero-stat-num">10<em>분</em></span>` 아래 레이블이 `<div class="hero-stat-label">1분 진단 · 즉시 결과</div>`로 되어 있어 숫자와 라벨의 단위 표기가 상이합니다.
   - **보류 사유**: 디자인 레이아웃 및 카피 기획 영역이므로 보류합니다.
3. **미사용 레거시 `QUESTIONS` 10문항 배열 (`index.html:2063-2165`)**:
   - **현상**: v3 시절의 10문항 배열이 인라인에 남아있으나, 현재는 `quiz-data.js`의 `CATEGORIES`를 사용하므로 실제 런타임에 아무런 영향을 주지 않는 Dead Code입니다.
   - **보류 사유**: 최소 변경 원칙에 따라 미사용 코드를 임의 정리하지 않고 원형을 유지했습니다.
4. **카카오 SDK JavaScript 키 미등록 (`index.html:2463`)**:
   - **현상**: `const KAKAO_JS_KEY = '';` 로 비어있어 카카오톡 공유 클릭 시 클립보드 복사(Fallback)로 동작합니다.
   - **보류 사유**: 외부 개발자 콘솔 키 발급이 필요한 운영 설정 항목입니다.
