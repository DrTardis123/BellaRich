## 3. `CATEGORY_META`와 `CATEGORIES`의 연결 및 불일치 분석

### 3.1 연결 구조 (`quiz-data.js:675-716`)
`CATEGORY_META` 배열은 카테고리 선택 화면(`#screen-category`)에서 5개 카드를 렌더링하기 위해 사용됩니다 (`index.html:2185-2200`).
* `CATEGORIES` 객체의 속성을 다음과 같이 직접 매핑합니다:
  * `title`: `CATEGORIES[k].title`
  * `subtitle`: `CATEGORIES[k].subtitle`
  * `icon`: `CATEGORIES[k].icon`
  * `desc`: `CATEGORIES[k].shortDesc`
* 여기에 각 카드 하단에 표시할 해시태그용 `keywords` 배열(5개씩)을 추가로 정의하고 있습니다.

### 3.2 중복 및 불일치 (미사용 필드) 분석
1. **`longDesc` 미사용**:
   * `CATEGORIES.tax.longDesc` 등 각 카테고리 객체에 정의된 긴 설명문은 클라이언트 HTML/JS 어디에서도 호출되거나 렌더링되지 않습니다 (`index.html:2190-2197`에서는 오직 `desc(=shortDesc)`만 표시).
2. **데이터 이중 관리**:
   * `id`, `title`, `subtitle`, `icon` 등 메타데이터가 `CATEGORIES`와 `CATEGORY_META` 양쪽에 걸쳐 중복 참조되고 있어, 향후 카테고리 추가/수정 시 2개 객체를 모두 갱신해야 하는 구조적 번거로움이 있습니다.
3. **HTML 내 레거시 코드 잔재 (`index.html:2063-2165`)**:
   * `index.html` 2063~2165줄에 v3/v4 시절의 구형 10문항 배열 `const QUESTIONS = [...]`가 그대로 남아있습니다. 이 변수는 현재 코드 어디에서도 참조되지 않는 **완전한 Dead Code**입니다.

## 4. 채점 로직 역설계 및 등급 매핑 수식

### 4.1 100점 환산 수식 (`index.html:2343-2354`)

`calcResult()` 함수는 사용자가 선택한 답변의 원점수 합을 해당 카테고리의 가능한 최대 원점수 합으로 나누어 100점 만점으로 정규화(Normalization)합니다.

$$\text{Score} = \text{round}\left( \frac{\sum_{i=0}^{N-1} \text{score}(answers[i])}{\sum_{i=0}^{N-1} \max_{j}(\text{score}(options_{i,j}))} \times 100 \right)$$

* $N = 6$ (각 카테고리별 문항 수)
* $\text{total} = \sum \text{score}(answers[i])$ (사용자가 획득한 원점수 합)
* $\text{max} = \sum \max(\text{options}_i)$ (해당 카테고리의 만점: `tax`=73, `realestate`=83, `succession`=76, `retirement`=72, `management`=72)
* 최종 점수는 `Math.round()`로 정수화되어 0~100 사이의 **"잠재 기회 지수"** 로 환산됩니다.

### 4.2 등급 경계값(Cut-off) 매핑 규칙 (`index.html:2355-2360`)

환산 점수($Score$)를 기준으로 모든 카테고리에 동일하게 다음 4단계 컷오프가 적용됩니다.

| 등급 | 조건 (환산 점수) | 의미 |
|:---:|:---:|---|
| **S** | $\text{Score} \ge 80$ | 전략적 완성/최적화 단계 (현 구조의 ROI 극대화 및 장기 로드맵 검토) |
| **A** | $60 \le \text{Score} < 80$ | 숨은 기회 발견 단계 (기본 구조는 갖추었으나 절세/수익 기회 누락 존재) |
| **B** | $40 \le \text{Score} < 60$ | 리스크 노출/보완 시점 (구조 미비로 인한 세금 누수 및 성장 한계 노출) |
| **C** | $\text{Score} < 40$ | 긴급 점검 필요 단계 (전 영역 리스크 동시 노출, 즉각적인 1:1 진단 필요) |

* **특징**: 카테고리별로 원점수 만점($max$)이 서로 다르지만, 백분율 환산 점수($Score$)를 산출한 후 동일한 80/60/40 경계값을 적용하므로 일관된 등급 판정이 이루어집니다.
