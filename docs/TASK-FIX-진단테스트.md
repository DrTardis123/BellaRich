## 1. 먼저 점검하라 (수정 전)

`index.html`(2,646줄)과 `quiz-data.js`(716줄)를 전부 읽고, 아래를 확인하라.

### A. 이미 확인된 오류 (메인 에이전트가 코드에서 직접 확인함 — 재확인 후 수정)

| ID | 내용 | 확인된 위치 |
|---|---|---|
| **E-01** | 파일 끝에 `</body></html>`가 **2번** 중복 | `index.html:2643-2646` |
| **E-02** | 인트로는 **"✕ 수집하지 않음: 이름, 이메일, 연락처"** 라고 단언하는데, 동의화면은 **이메일 필수 입력**. 정면 충돌 (개인정보 고지 오류) | `index.html:1626` ↔ `index.html:1769` |
| **E-03** | 동의화면 제출 버튼에 중복 클릭 방지가 없음 → `submitConsent()`가 두 번 돌면 시트 중복 행 + 메일 중복 발송 | `index.html:2307~` (`submitConsent`), `2404` (`sendData(true)`) |

E-02는 **문구를 사실에 맞게 고치는 것**이 수정 방향이다. 이메일 수집을 없애는 게 아니다.
(현재 동작이 정상이고, 인트로 고지가 틀렸다.)

### B. 이미 확인된 "정상" — 건드리지 마라

메인 에이전트가 직접 검증했다. 여기서 "문제 발견"을 새로 만들어내지 마라.

- 채점식 `Math.round((total / max) * 100)`, `max`를 카테고리별 동적 합산 → 100점 초과/0점 미만 불가 (`index.html:2349-2353`)
- 미응답 상태로 다음 문항 진행 불가 → `NaN` 유입 경로 없음 (`index.html:2257`, `2271`)
- `CATEGORY_META` ↔ `CATEGORIES` 5개 키 전부 일치, 필드 불일치 0건
- 카테고리별 원점수 만점 편차(73/83/76/72/72)는 정규화로 흡수됨 — **의도된 설계로 보고 손대지 마라**

### C. 네가 새로 찾아야 할 것

1. **JS 런타임 오류** — 브라우저 콘솔에 뜨는 에러/경고 전문. 없으면 "없음"이라고 써라.
2. **깨진 참조** — 존재하지 않는 `getElementById` 대상, 404 나는 리소스(이미지/폰트/SDK), 오타 난 클래스명
3. **호출되지 않는 함수 / 연결 안 된 버튼** — 정의만 되고 아무 데서도 안 쓰이는 함수, `onclick`이 없는 버튼
4. **결과 화면 정합성** — 화면에 표시되는 값과 실제 계산값이 어긋나는 곳
5. **문구 오류** — 오탈자, 사실과 다른 안내, 다른 카테고리 내용이 잘못 들어간 결과 카피
   (특히 v7에서 추가된 `retirement`·`management` 두 카테고리를 의심하고 정독)
6. **외부 링크** — 빈 `href`, `#` 방치, 오탈자 난 URL
